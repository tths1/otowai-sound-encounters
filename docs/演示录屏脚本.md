# 《音逢》演示录屏脚本

建议总时长：**6 分钟左右**（符合 5–8 分钟要求）。成片使用**横屏 MP4、1920×1080 或更高、普通话讲解、建议配字幕**。公开体验端：<https://otowai-sound-encounters.netlify.app/>。

## 0:00—0:40｜开场与问题背景

画面：网站首页顶部，停在作品标题和主按钮。

> 大家好，我的参赛作品是《音逢｜中日谐音文化小志》。这是一个中日声音联想互动网页。它不做中文到日文的语义翻译，而是让用户输入一句中文后，体验它在日语假名中的趣味“空耳”读法。
>
> 我希望解决的问题是：语言文化类内容常常只能阅读，用户很难直接听到、尝试和修正声音联想。音逢把这个过程做成可输入、可生成、可朗读、可维护的互动体验。

操作：缓慢滚动，展示首页视觉、每日谐音与“项目说明”。

## 0:40—1:25｜项目定位与词集搜索

画面：停在“项目说明”，再进入“谐音词集”。在搜索框输入 `桃花`。

> 项目以“声音联想”而不是“语言等同”为边界。比如“忽逢桃花林”在这里可以体验为“ふーふん たお はりん”。这是一种可玩的音感表达，并不声称现代中文和日文存在严格的一一对应。
>
> 词集可以按中文、假名或出处搜索。每条词条都可以直接试听，帮助用户先建立声音直觉，再进入自己的句子创作。

操作：点击一条结果的扬声器图标。

## 1:25—2:35｜核心功能：空耳制造器

画面：点击“空耳制造器”，输入 `今天我们一起学习中文`，点击“生成对应句子”。

> 空耳制造器是作品的核心。这里输入一句中文，系统会按字符逐一处理，并优先读取经过维护的拼音—假名规则。
>
> 一个关键设计是：它不允许意译。比如“我”不会因为语义被转换成“わたし”；系统关注的是原字的中文读音和日语假名的音感接近程度。
>
> 同音字会复用同一条规则，因此同一个读音在不同句子中的输出会保持一致。对于“行”这类多音字，则按 xing、hang 等不同拼音分别维护，避免把不同读音混在一起。

操作：展示原句、生成假名、字符映射；再输入 `他和她今天同学聚会`，展示逐字结果。

## 2:35—3:30｜朗读时长自动匹配

画面：点击“朗读生成句子”，等待页面显示中文时长、假名时长和自动语速信息。

> 仅仅把假名读出来还不够，因为假名往往比中文原句更长，会拖慢节奏。
>
> 因此，系统会在浏览器中先静音测量中文原句和生成假名的基准朗读时长，再用“假名时长除以中文时长”计算播放语速。这样，生成句子尽量能在和原句接近的时间内读完。
>
> 用户仍可以使用滑条微调速度；这让算法自动匹配与个人听感调整可以同时存在。

操作：指向时长提示与速度控制条；播放一次生成结果。

## 3:30—4:20｜体验与可用性设计

画面：刷新快速试句；展示最近历史；切换深色模式；缩窄浏览器窗口展示手机布局。

> 为了让这个工具适合持续尝试，我加入了快速试句、最近生成历史、词集搜索和深色模式。按钮有轻微反馈，页面也会根据手机和电脑自动调整布局。
>
> 公开页面不会显示规则编辑功能，普通用户可以直接使用生成器；规则维护与公开体验分离，避免未校对内容被任意修改。

## 4:20—5:15｜规则维护与系统架构

画面：展示技术文档的架构图；如展示管理端，仅展示规则表，不展示账户、密钥或平台控制台。

> 在架构上，前端使用 HTML、CSS 和原生 JavaScript 完成交互，浏览器通过 Web Speech API 朗读。主题、历史和草稿保存在本地；管理员映射规则则通过 Netlify Functions 和 Netlify Blobs 保存。
>
> 规则层的优先级是：人工校对的拼音规则第一，其次是已有同音字复用，再之后才是自动生成的待校对候选和音节回退策略。这个优先级保证用户和维护者已经确认过的读音不会被自动结果覆盖。

## 5:15—5:45｜AI 技术使用说明

画面：打开仓库中的 `docs/AI辅助开发记录.md` 或技术文档的“AI 技术使用说明”页。

> 本作品采用 AI 辅助开发：AI 帮助我梳理需求、比较交互方案、审查代码和设计测试样例；每一条音感规则都必须由我试听和校对后才能进入字库。
>
> 为保证低成本、稳定性和隐私，公开网站运行时不调用付费大模型，也不会把访客输入发送给第三方模型。实际转换由可解释、可维护的规则引擎完成。

## 5:45—6:10｜测试、部署与结尾

画面：回到公开网址首页，显示地址栏；可短暂展示 GitHub 仓库 README。

> 我已针对中文、日文、混合输入、同音字复用、多音字区分、复制、朗读、历史、深色模式和手机布局进行测试，并将作品部署为可公开访问的网站。
>
> 《音逢》尝试让中日声音文化从静态展示变成可听、可玩、可不断校对的互动体验。后续我会继续扩充人工校对字库，并探索更多汉字音系比较。谢谢观看。

## 录制检查

- 录制前在无痕窗口打开公开地址，避免缓存影响；
- 使用普通话讲解，建议加入同步中文字幕；
- 保证视频 5–8 分钟、1080p 以上、MP4；
- 不展示管理密码、Netlify 控制台密钥、GitHub 令牌或个人隐私信息；
- 若手机不支持 Web Speech API，请使用桌面浏览器演示朗读，并在字幕中说明“设备语音能力由浏览器提供”。
